# carapace-shortcutter (pacecut)
## Description
carapace-shortcutter is a command-line utility that allows you to make shortcuts of existing commands. Unlike the `alias` command, it also allows you to link aliases to Lua scripts, for automation and ease of use.

## Run it
### Dependencies
- `git`
- `rustup`
- A Unix-basedw operating system (macOS, Linux, BSD), Windows is not yet supported.
